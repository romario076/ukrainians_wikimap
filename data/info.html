🌍 Наші Люди Всюди 🌍 Our People Everywhere

Першопочатково ідея проєкту полягала в тому, щоб відобразити на мапі світу місця народження українців, які мають статтю на Вікіпедії. Тоді за основу аналізу було взято 28 000 статей з Вікіпедії. Originally, the project idea was to map the birthplaces of Ukrainians who have an article on Wikipedia. At that time, the analysis was based on 28,000 Wikipedia articles.

Тепер же, оновлена версія карти відображає інформацію, зокрема не тільки місця народження, але і місця смерті, про більше ніж 60 000 особистостей, які таким чи іншим чином пов'язані з Україною чи її історичними формуваннями, наприклад УНР чи Гетьманщина. Now, the updated version of the map displays information about not only birthplaces but also places of death for more than 60,000 personalities who are in one way or another connected to Ukraine or its historical formations, such as the Ukrainian People's Republic or the Hetmanate.

Also, clicking on a point opens the corresponding Wikipedia page for more details.

🧠 Еволюція збору даних: Класичний метод (Ручне дослідження) 🧠 Data Collection Evolution: Classic Method (Manual Research)

Для перших версій проєкту та для індивідуального точкового пошуку використовувався (і може успішно використовуватись вами зараз) класичний метод — прямий інструмент SPARQL-запитів до WikiData. Ви можете застосовувати цей сервіс для самостійного вивчення відкритих даних та маніпуляції з ними вручну. For the early versions of the project and for individual spot searches, the classic method was used (and can still be used by you today) — direct SPARQL queries to WikiData. You can use this service to independently explore open data and manipulate it manually.

Цей SPARQL-запит отримує інформацію про осіб, які пов'язані з Україною (як сучасною державою, так і її історичними формуваннями), та мають сторінку у українській Вікіпедії. Результатом роботи запиту є дані про місце народження, їх координати, дату народження, якщо відомо: місце смерті, їх координати, стать та інше. This SPARQL query retrieves information about persons connected to Ukraine (both as a modern state and its historical formations) who have a page on Ukrainian Wikipedia. The query result includes birthplace, its coordinates, date of birth, and if known: place of death, its coordinates, gender, and more.

Сервіс запитів Вікіданих (Wikidata Query Service) Wikidata Query Service : https://query.wikidata.org

Вікідані (Wikidata): Wikidata: Це велика безкоштовна, спільна, багатомовна база знань, яка збирає структуровані дані для підтримки Вікіпедії та інших проєктів Фонду Вікімедіа. У Вікіданих зберігаються факти про мільйони об'єктів та їхні взаємозв'язки. A large, free, collaborative, multilingual knowledge base that collects structured data to support Wikipedia and other Wikimedia Foundation projects. Wikidata stores facts about millions of entities and their relationships.

SELECT ?person ?personLabel ?birthplaceLabel ?birthDate ?deathDate
	?deathplaceLabel ?wikipedia_url ?genderLabel ?affiliationLabel
	WHERE {
	  ?person wdt:P31 wd:Q5.                          
	  VALUES ?affiliation {
		wd:Q212                #Ukraine
	  }

	  ?person wdt:P27 ?affiliation.       
	  ?person wdt:P19 ?birthplace.
	  ?person wdt:P569 ?birthDate.
	  
	  OPTIONAL { ?person wdt:P570 ?deathDate. }
	  OPTIONAL { ?person wdt:P20 ?deathplace. } 

	  OPTIONAL { ?person wdt:P21 ?gender. }
      OPTIONAL { ?wikipedia schema:about ?person;
               schema:isPartOf <https://uk.wikipedia.org/>.}
	  SERVICE wikibase:label { bd:serviceParam wikibase:language "uk". }
	}

🚀 Data Extractor: Нова ера автоматизованого збору даних 🚀 Data Extractor: A New Era of Automated Data Collection

Хоча класичні SPARQL-запити чудово підходять для ручних досліджень, глобальне масштабування проєкту вимагало радикально іншого підходу. Великі запити часто стикалися з тайм-аутами серверів Wikidata або пропускали постатей через брак тегів у базі даних. While classic SPARQL queries are excellent for manual research, the global scaling of the project demanded a radically different approach. Large queries often ran into Wikidata server timeouts or missed figures due to incomplete tagging in the database.

Тому в новій версії було впроваджено Data Extractor — інтелектуальний високопродуктивний конвеєр, що поєднує потужність семантичного аналізу, асинхронних технологій та геопросторової математики. Therefore, the new version introduced the Data Extractor — an intelligent high-performance pipeline combining the power of semantic analysis, asynchronous technologies, and geospatial mathematics.

Кожен розробник або дослідник даних може самостійно розгорнути та запустити Data Extractor для власних аналітичних цілей, знайшовши його у нашому офіційному GitHub-репозиторії. 📢 Open Source: Since our project is built on Open Source principles, the tool's architecture is fully open! Any developer or data researcher can independently deploy and run the Data Extractor for their own analytical purposes by finding it in our official GitHub repository.

🛠 Чому це справжній технологічний прорив? 🛠 Why Is This a True Technological Breakthrough?

  • Гібридне виявлення (Multi-path Discovery): Multi-path Discovery: Замість лінійного пошуку система використовує 7 незалежних паралельних шляхів розвідки. Постаті ідентифікуються не лише за громадянством, а й за іншими складними ознаками та категоріями у світових архівах Вікіпедії. Instead of linear search, the system uses 7 independent parallel discovery paths. Figures are identified not only by citizenship but also by other complex attributes and categories across global Wikipedia archives.
  • Асинхронне ядро на максимальних швидкостях: Asynchronous Core at Maximum Speed: Завдяки технологічному стеку httpx + asyncio, скрипт обробляє тисячі запитів одночасно. Розумна архітектура семафорів і динамічне балансування навантаження дозволяють викачувати гігабайти інформації миттєво, повністю уникаючи блокувань з боку API. Thanks to the httpx + asyncio stack, the script processes thousands of requests simultaneously. Smart semaphore architecture and dynamic load balancing allow downloading gigabytes of data instantly, completely avoiding API rate limits.
  • Геометрія замість слів (Ray-casting алгоритм): Geometry Instead of Words (Ray-casting Algorithm): Якщо в текстовому профілі особи прямо не вказано країну, Data Extractor задіює геопросторову математику. Алгоритм Ray-casting аналізує координати народження і зіставляє їх із масивом складних математичних полігонів історичних кордонів України. Якщо точка всередині — система автоматично зараховує особу до датасету. If a person's text profile does not explicitly state the country, the Data Extractor activates geospatial mathematics. The Ray-casting algorithm analyzes birth coordinates and maps them against an array of complex mathematical polygons representing Ukraine's historical borders. If the point is inside — the system automatically includes the person in the dataset.
  • Семантичний ШІ-фільтр у реальному часі: Real-time Semantic AI Filter: Інструмент сканує вступні тексти статей, миттєво відсіюючи інформаційне сміття та залишаючи в базі лише тих діячів, які дійсно мають вагоме значення для глобальної карти. The tool scans article introductory texts, instantly filtering out informational noise and retaining only those figures who truly have significant relevance for the global map.

  • Етнічні маркери та субпопуляції: Ethnic Markers and Subpopulations: Завдяки новій логіці алгоритму, система вміє розпізнавати осіб за їхнім корінним походженням, належністю до унікальних етнографічних груп або важливих національних спільнот, що століттями розвивалися на теренах України (код wdt:P172).   • Глобальна діаспора та мовний простір: Global Diaspora and Language Space: У датасет автоматично залучаються представники численних хвиль української еміграції, а також особи, для яких рідною або основною мовою діяльності зафіксована українська (коди wdt:P103 / wdt:P1412). The dataset automatically includes representatives of numerous waves of Ukrainian emigration, as well as persons whose native or primary working language is recorded as Ukrainian (codes wdt:P103 / wdt:P1412).
  • Обов'язкові умови: Mandatory Conditions: Наявність активної сторінки в українській Вікіпедії, чітко верифікована дата народження та наявність географічних координат місця народження для коректної побудови інтерактивних точок на мапі. An active page on Ukrainian Wikipedia, a clearly verified date of birth, and the presence of geographic coordinates of the birthplace for correct rendering of interactive points on the map.

📊 Кластеризація та AI-аналіз (Демо-версія) 📊 Clustering and AI Analysis (Demo Version)

У цьому розділі реалізовано інтелектуальний аналіз та автоматичне групування (кластеризацію) видатних постатей на основі текстового опису їхньої діяльності в отриманому датасеті. Це дозволяє виявити приховані зв'язки та сформувати семантичні спільноти людей за сферами їхнього впливу, професіями чи історичним контекстом. This section implements intelligent analysis and automatic clustering of prominent figures based on textual descriptions of their activities in the dataset. This reveals hidden connections and forms semantic communities of people by their spheres of influence, professions, or historical context.

⚙️ Як це працює з технічної точки зору: ⚙️ How it Works Technically:

  • Фільтрація та якість даних:Data Filtering and Quality: Для побудови точної моделі аналізу було відібрано лише тих осіб, для яких вдалося отримати якісний та змістовний опис обсягом понад 30 символів. Only persons with a quality, meaningful description of more than 30 characters were selected to build an accurate analysis model.
  • Ембедінг (Текст як вектори):Embedding (Text as Vectors): За допомогою сучасної мовної ШІ-моделі intfloat/multilingual-e5-small кожен текстовий опис трансформується у високорозмірний математичний вектор із 384 вимірами. Ця числова репрезентація кодує глибокий семантичний зміст тексту. Using the modern AI language model intfloat/multilingual-e5-small, each text description is transformed into a high-dimensional mathematical vector with 384 dimensions. This numeric representation encodes the deep semantic meaning of the text.
  • Стиснення простору (UMAP):Dimensionality Reduction (UMAP): Оскільки людський мозок фізіологічно не здатний сприймати простір, який має більше 3-х вимірів, ми застосовуємо складні топологічні алгоритми зниження розмірності UMAP. Вони акуратно згортають 384-вимірний простір смислів у зрозумілу для людини 2-вимірну площину, зберігаючи при цьому глобальні та локальні зв'язки між об'єктами. Since the human brain cannot perceive spaces with more than 3 dimensions, we apply the complex topological UMAP dimensionality reduction algorithms. They neatly compress the 384-dimensional semantic space into a human-readable 2D plane, preserving global and local relationships between objects.
  • Пошук закономірностей (HDBSCAN):Pattern Finding (HDBSCAN): Фінальний етап побудови карт знань покладено на алгоритм щільнісної кластеризації HDBSCAN. Він автоматично розпізнає згущення векторів на площині, ідентифікує межі кластерів та виділяє схожі групи людей в окремі тематичні блоки, відсіюючи випадковий інформаційний шум. The final stage of building knowledge maps relies on the density-based clustering algorithm HDBSCAN. It automatically detects vector clusters on the plane, identifies cluster boundaries, and groups similar people into separate thematic blocks, filtering out random noise.

⚠️ Примітка: Наразі функціонал працює в режимі демо-версії, оскільки використовує безплатну полегшену ембедінг-модель. Попри це, вона демонструє дивовижну непогану точність та відкриває цікавий погляд на структурування української історичної спадщини. Note: The functionality currently operates in demo mode as it uses a free lightweight embedding model. Despite this, it demonstrates surprisingly good accuracy and offers an interesting perspective on structuring Ukrainian historical heritage.

❓ FAQ

Чому стаття про певну людину не потрапила в аналіз? Why didn't an article about a certain person appear in the analysis?

  • Її немає в українській Вікіпедії або її опис занадто короткий для семантичного ШІ-сита. It is not in Ukrainian Wikipedia, or its description is too short for the semantic AI filter.
  • Не виконується одна з обов'язкових технічних умов автоматичного відбору (не вказано точні координати або відсутній верифікований лінк між Wikidata та Wikipedia). One of the mandatory technical conditions for automatic selection is not met (exact coordinates are missing or the verified link between Wikidata and Wikipedia is absent).
  • Стаття містить критичні помилки розмітки, через що автоматичний багатопотоковий парсер відфільтрував її як пошкоджену для забезпечення чистоти фінальної мапи. The article contains critical markup errors, causing the automatic multi-threaded parser to filter it as corrupted to ensure the cleanliness of the final map.

Чому точки опиняються на річці, озері чи далеко від центру міста? Why do points appear on a river, lake, or far from the city center?

  • Кожне місто або село має одну офіційну координату. Якщо для цього населеного пункту знайдено 100 осіб, усі позначки наклалися б одна на одну. Щоб цього уникнути, до координат додається штучний статистичний шум: позначки «розпорошуються» навколо офіційної точки, тож кожного видатного українця видно окремо. Every city or village has one official coordinate. If 100 people are found for that location, all markers would overlap. To avoid this, artificial statistical noise is added to the coordinates: markers are "scattered" around the official point, so each prominent Ukrainian is visible separately.
